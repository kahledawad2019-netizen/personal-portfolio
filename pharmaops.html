PharmaOps AI

A research-only manufacturing intelligence prototype that brings together traceable batch-level data, process analytics, predictive-quality experiments, and investigation workflows. Designed around auditability rather than inflated model-performance claims.

Problem and approach

Pharmaceutical production records can be difficult to investigate across raw-material QC, in-process controls, high-frequency compression data, and final tablet-quality measurements. PharmaOps AI explores whether a transparent analytical workflow can help an analyst understand a batch and evaluate early quality estimates.

01 · Data governanceVerified source download, schema audit, feature timing contract, reconciliation and reproducible builds.
02 · Analytics and MLBatch-level KPIs, chronological evaluation, baseline comparison, error analysis and SHAP explanations.
03 · InvestigationBatch explorer, model limitations, documented evidence gaps and drift-monitoring views.

What's implemented

  • Data pipeline: MD5-verified source data, audit of 90 source columns, 1,005/1,005 batch reconciliation, process time series in Parquet, and DuckDB analytics with SHA-256 build manifests.
  • Modeling: temporal split with forward cross-validation, Dummy/Ridge/Random Forest baselines, documented feature availability before final QC, bootstrap confidence intervals and per-product-code error analysis.
  • Interactive product: Streamlit views for Overview, Batch Explorer, Quality Prediction, and Investigation Workbench with a structured, evidence-linked investigation report.
  • Monitoring: Population Stability Index (PSI), missingness by data source, batch composition and out-of-sample residual trends, explicitly treated as descriptive indicators.
  • Engineering discipline: data contracts, a model card, reproducible scripts, unit/integration tests, Ruff checks, runbook, acceptance criteria and independent review logs.

Held-out model evaluation

The prediction stage is the end of tablet compression; the target is the final dissolution measurement. The primary model uses 57 features whose availability is documented at that cutoff.

MetricReported result
Holdout period and sizeNovember 2020–April 2021 · 211 batches
Selected Random Forest MAE2.43 percentage points
Training-mean baseline MAE2.83 percentage points
Selected model R² (95% CI)0.041 (−0.084 to 0.144)

Interpretation: The model modestly improves MAE over the simple baseline but does not meaningfully explain within-product quality variation. Results are not a validated GMP decision tool, QC substitute, production release rule, or root-cause proof.

Data provenance and availability

Built using a public pharmaceutical manufacturing dataset from Žagar & Mihelič (2022), Scientific Data 9:99. Read the original research. The project repository is currently private; code and a walkthrough can be discussed upon request.
